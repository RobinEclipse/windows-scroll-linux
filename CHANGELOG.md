# Windows Scroll Linux

## v1

First public release.

- Click the mouse wheel to start scrolling and move the mouse to control it.
- Hold the wheel for temporary scrolling.
- Stop with another mouse button, the wheel or Escape.
- Block ordinary middle-click paste on handled mice, including while paused.
- Preserve native middle-click actions on verified tabs and links.
- Change speed, direction and pointer indicator settings.
- Start automatically at login.
- Install on a fresh supported Linux system or update an existing installation.

The input engine uses Rust. Desktop integration runs separately as the signed-in
user. The public version starts at v1; internal protocol numbers are independent
of the release name.
